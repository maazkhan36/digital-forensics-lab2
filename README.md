# digital-forensics-lab2
Topics Covered
Number Systems & Timestamps: Base conversions (hex, binary, decimal) and epoch timestamp decoding (Unix, Mac Absolute Time).

System Layers & Processes: Mapping evidence across user, application, OS, disk, and memory layers; inspecting process trees.

Disk & Partition Analysis: Sector calculations, MBR vs. GPT comparison, and safe partition table inspection.

File Systems: Identifying file systems (NTFS, FAT32, ext4) and understanding forensic metadata.
